## 📝 Solution Categories

### Arrays

Problems involving traversal, searching, manipulation, prefix techniques, and optimization.

### Strings

Problems involving string manipulation, character frequency, matching, and pattern recognition.

### Hashing

Problems using dictionaries, sets, and frequency counting for efficient lookups.

### Linked Lists

Problems involving singly linked lists, manipulation, reversal, merging, and pointer techniques.

### Stack & Queue

Problems involving LIFO/FIFO concepts, monotonic stacks, and queue-based techniques.

### Recursion & Backtracking

Problems involving recursive exploration, decision making, constraint satisfaction, and state restoration.

### Trees & Graphs

Problems involving traversal, DFS, BFS, connectivity, and graph-based problem solving.

### Dynamic Programming

Problems involving overlapping subproblems, optimal substructure, memoization, and tabulation.
